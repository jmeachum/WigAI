# WigAI Documentation Index

## Project Overview

- **Type:** monolith
- **Primary Language:** Java 21
- **Architecture:** Layered service/API-centric backend extension

## Quick Reference

- **Tech Stack:** Java 21, Gradle 8.13, Jetty 11, MCP Java SDK 0.11.0
- **Entry Point:** `WigAIExtension` / `WigAIExtensionDefinition`
- **MCP Endpoint:** `http://localhost:61169/mcp` (loopback-only by default)
